Régie5 for PS5 — installation / Installation de Régie5 sur PS5
==============================================================

ENGLISH
-------

You need
- A jailbroken PS5 running ShadowMount+ (it turns folders in /data/homebrew/
  into home-screen tiles). Tested on firmware 13.60.
- A way to copy a folder to the console: ps5upload, or an FTP server payload.
- Your Sonarr, Radarr, Seerr and/or Jellyfin (or Emby, or Plex), reachable
  from the console on your local network, and their API keys.

First install
1. Unzip this archive on your computer. It holds one folder: PPSA99520.
2. Copy the whole PPSA99520 folder into /data/homebrew/ on the console, so that
   /data/homebrew/PPSA99520/eboot.bin exists.
3. Wait about ten seconds: ShadowMount+ adds the "Régie5" tile to the home
   screen, under Games. (If it does not appear, restart ShadowMount+ or the
   console.)
4. Open Régie5. At the first start, its set-up screens open: choose
   "Get started", then your media server (Jellyfin, Emby, Plex or None). A QR
   code and a 6-digit code appear on the TV.
5. Scan the QR code with your phone (same network as the console), or type the
   address shown on the TV into the phone's browser.
6. On the page, fill in each service: address (http:// or https://, with the
   port, e.g. http://192.168.1.10:8989) and API key. Tick "Self-signed
   certificate" for an https:// address with a self-signed certificate.
7. Tap "Save on the console". Régie5 tests every service: each one should get a
   green dot. "Start" opens the Home screen.

"Later" closes the set-up screens; they then stay closed. To open them again:
"Set up" on the Home screen, or Settings (press R1 until the gear is selected)
> "Setup". Settings > "From a phone" opens the same phone page directly.

If Régie5 closes twice in a row right after starting with the same
config.json, the next start does not load it (the file is not changed): the
set-up screens open with a message, to fix it from the phone. Settings >
"Test all" reads the file again.

Without a phone: copy PPSA99520/config.example.json to config.json in the same
folder, fill it in on your computer, copy it to /data/homebrew/PPSA99520/, then
choose "Test all" in Settings.

Where to find the API keys
- Sonarr, Radarr: Settings > General > Security > API Key.
- Seerr: Settings > General > API Key.
- Jellyfin: Dashboard > API Keys > "+". Or no key at all: give only
  Jellyfin's address, then Settings > Jellyfin's line > Options > Quick
  Connect, and type the code shown in Jellyfin on your phone (your profile >
  Quick Connect), with an administrator account.
- Emby: the server's settings > Advanced > Api Keys > New Api Key.

Emby instead of Jellyfin (beta): in config.json, the key is "emby" instead of
"jellyfin" (same fields). The tab and the texts then say Emby, and Options
offers "Find in Emby5".

Plex instead of Jellyfin (beta, new in 0.6.0): on the phone page, give Plex's
address (port 32400), then tap "Sign in to Plex" (the phone needs the
internet for it, the console does not) and sign in as the server's owner.
Options offers "Find in Plex"; Cleanup is not available with Plex yet.
Plex users: please open an issue with your feedback, even if everything works:
https://github.com/viviandsx/regie5/issues/new?template=plex_feedback.yml

Updating
- Copy the new PPSA99520 folder OVER the old one. The zip never holds a
  config.json: yours is kept, and the set-up screens do not open.
- Do not delete the old folder first. If that happens anyway, Régie5 uses the
  copy of config.json it keeps on its side, and Settings says so.

Good to know
- Régie5 only talks to your own servers on your local network: nothing goes to
  the internet (signing in to Plex goes to plex.tv from your phone, not from
  the console).
- config.json holds your API keys in plain text on the console.
- Cleanup (deleting films and series with their files) is off by default; it is
  turned on in Settings, after a warning, and every deletion asks twice.
- "Open in Jelly5" is not possible: the console does not let one app start
  another. Options > "Find in Jelly5" (or "Find in Emby5", "Find in Plex")
  tells you which title to look for there.
- Uninstall: delete /data/homebrew/PPSA99520.

FRANÇAIS
--------

Il faut
- Une PS5 jailbreakée avec ShadowMount+ (il transforme les dossiers de
  /data/homebrew/ en tuiles sur l'écran d'accueil). Testé en firmware 13.60.
- Un moyen de copier un dossier sur la console : ps5upload, ou un payload
  serveur FTP.
- Votre Sonarr, Radarr, Seerr et/ou Jellyfin (ou Emby, ou Plex), joignables
  depuis la console sur votre réseau local, et leurs clés d'API.

Première installation
1. Décompressez cette archive sur votre ordinateur. Elle contient un seul
   dossier : PPSA99520.
2. Copiez tout le dossier PPSA99520 dans /data/homebrew/ sur la console :
   /data/homebrew/PPSA99520/eboot.bin doit exister.
3. Attendez une dizaine de secondes : ShadowMount+ ajoute la tuile « Régie5 »
   sur l'écran d'accueil, dans Jeux. (Sinon, relancez ShadowMount+ ou la console.)
4. Ouvrez Régie5. Au premier lancement, son assistant s'ouvre : choisissez
   « Commencer », puis votre serveur multimédia (Jellyfin, Emby, Plex ou
   Aucun). Un QR code et un code à 6 chiffres s'affichent sur la télé.
5. Scannez le QR code avec votre téléphone (même réseau que la console), ou
   tapez dans son navigateur l'adresse affichée sur la télé.
6. Sur la page, remplissez chaque service : adresse (http:// ou https://, avec
   le port, par exemple http://192.168.1.10:8989) et clé d'API. Cochez
   « Certificat auto-signé » pour une adresse https:// au certificat auto-signé.
7. Touchez « Enregistrer sur la console ». Régie5 teste chaque service : chacun
   doit avoir une pastille verte. « Commencer » ouvre l'Accueil.

« Plus tard » ferme l'assistant ; il ne s'ouvre plus tout seul. Pour le
rouvrir : « Configurer » sur l'Accueil, ou Réglages (R1 jusqu'à l'engrenage)
> « Assistant ». Réglages > « Depuis le téléphone » ouvre directement la même
page du téléphone.

Si Régie5 se ferme deux fois de suite juste après son lancement avec le même
config.json, le lancement suivant ne le charge pas (le fichier n'est pas
modifié) : l'assistant s'ouvre avec un message, pour le corriger depuis le
téléphone. Réglages > « Tout tester » relit le fichier.

Sans téléphone : copiez PPSA99520/config.example.json sous le nom config.json
dans le même dossier, remplissez-le sur votre ordinateur, copiez-le dans
/data/homebrew/PPSA99520/, puis choisissez « Tout tester » dans Réglages.

Où trouver les clés d'API
- Sonarr, Radarr : Settings > General > Security > API Key.
- Seerr : Settings > General > API Key.
- Jellyfin : Tableau de bord > Clés API > « + ». Ou aucune clé : donnez
  seulement l'adresse de Jellyfin, puis Réglages > ligne Jellyfin > Options >
  Quick Connect, et tapez le code dans Jellyfin sur le téléphone (votre
  profil > Quick Connect), avec un compte administrateur.
- Emby : réglages du serveur > Advanced > Api Keys > New Api Key (interface
  en anglais).

Emby à la place de Jellyfin (bêta) : dans config.json, la clé est "emby" au
lieu de "jellyfin" (mêmes champs). L'onglet et les textes disent alors Emby,
et Options propose « Chercher dans Emby5 ».

Plex à la place de Jellyfin (bêta, nouveau en 0.6.0) : sur la page du
téléphone, donnez l'adresse de Plex (port 32400), puis touchez « Se connecter
à Plex » (le téléphone doit avoir internet, la console non) et connectez-vous
avec le compte propriétaire du serveur. Options propose « Chercher dans
Plex » ; le Ménage n'est pas encore disponible avec Plex.
Utilisateurs de Plex : ouvrez une issue avec vos retours, même si tout marche :
https://github.com/viviandsx/regie5/issues/new?template=plex_feedback.yml

Mise à jour
- Copiez le nouveau dossier PPSA99520 PAR-DESSUS l'ancien. Le zip ne contient
  jamais de config.json : le vôtre est conservé, et l'assistant ne s'ouvre
  pas.
- Ne supprimez pas l'ancien dossier avant. Si cela arrive quand même, Régie5
  reprend la copie de config.json qu'il garde de son côté, et Réglages
  l'indique.

À savoir
- Régie5 ne parle qu'à vos serveurs, sur votre réseau local : rien ne part sur
  internet (la connexion à Plex passe par plex.tv depuis votre téléphone, pas
  depuis la console).
- config.json contient vos clés d'API en clair sur la console.
- Le Ménage (suppression de films et séries avec leurs fichiers) est désactivé
  par défaut ; il s'active dans Réglages, après un avertissement, et chaque
  suppression demande deux confirmations.
- « Ouvrir dans Jelly5 » n'est pas possible : la console ne laisse pas une app
  en lancer une autre. Options > « Chercher dans Jelly5 » (ou « Chercher dans
  Emby5 », « Chercher dans Plex ») indique le titre à y chercher.
- Désinstaller : supprimez /data/homebrew/PPSA99520.
