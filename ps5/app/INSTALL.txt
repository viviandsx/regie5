Régie5 for PS5 — installation / Installation de Régie5 sur PS5
==============================================================

ENGLISH
-------

You need
- A jailbroken PS5 running ShadowMount+ (it turns folders in /data/homebrew/
  into home-screen tiles). Tested on firmware 13.60.
- A way to copy a folder to the console: ps5upload, or an FTP server payload.
- Your Sonarr, Radarr, Seerr and/or Jellyfin, reachable from the console on
  your local network, and their API keys.

First install
1. Unzip this archive on your computer. It holds one folder: PPSA99520.
2. Copy the whole PPSA99520 folder into /data/homebrew/ on the console, so that
   /data/homebrew/PPSA99520/eboot.bin exists.
3. Wait about ten seconds: ShadowMount+ adds the "Régie5" tile to the home
   screen, under Games. (If it does not appear, restart ShadowMount+ or the
   console.)
4. Open Régie5. Press R1 until the gear (Settings) is selected.
5. Choose "From a phone". A QR code and a 6-digit code appear on the TV.
6. Scan the QR code with your phone (same network as the console), or type the
   address shown on the TV into the phone's browser.
7. On the page, fill in each service: address (http:// or https://, with the
   port, e.g. http://192.168.1.10:8989) and API key. Tick "Self-signed
   certificate" for an https:// address with a self-signed certificate.
8. Tap "Save on the console". Régie5 tests every service: each one should get a
   green dot in Settings.

Without a phone: copy PPSA99520/config.example.json to config.json in the same
folder, fill it in on your computer, copy it to /data/homebrew/PPSA99520/, then
choose "Test all" in Settings.

Where to find the API keys
- Sonarr, Radarr: Settings > General > Security > API Key.
- Seerr: Settings > General > API Key.
- Jellyfin: Dashboard > API Keys > "+".

Updating
- Copy the new PPSA99520 folder OVER the old one. The zip never holds a
  config.json: yours is kept.
- Do not delete the old folder first. If that happens anyway, Régie5 uses the
  copy of config.json it keeps on its side, and Settings says so.

Good to know
- Régie5 only talks to your own servers on your local network: nothing goes to
  the internet.
- config.json holds your API keys in plain text on the console.
- Cleanup (deleting films and series with their files) is off by default; it is
  turned on in Settings, after a warning, and every deletion asks twice.
- "Open in Jelly5" is not possible: the console does not let one app start
  another. Options > "Find in Jelly5" tells you which title to look for there.
- Uninstall: delete /data/homebrew/PPSA99520.

FRANÇAIS
--------

Il faut
- Une PS5 jailbreakée avec ShadowMount+ (il transforme les dossiers de
  /data/homebrew/ en tuiles sur l'écran d'accueil). Testé en firmware 13.60.
- Un moyen de copier un dossier sur la console : ps5upload, ou un payload
  serveur FTP.
- Votre Sonarr, Radarr, Seerr et/ou Jellyfin, joignables depuis la console sur
  votre réseau local, et leurs clés d'API.

Première installation
1. Décompressez cette archive sur votre ordinateur. Elle contient un seul
   dossier : PPSA99520.
2. Copiez tout le dossier PPSA99520 dans /data/homebrew/ sur la console :
   /data/homebrew/PPSA99520/eboot.bin doit exister.
3. Attendez une dizaine de secondes : ShadowMount+ ajoute la tuile « Régie5 »
   sur l'écran d'accueil, dans Jeux. (Sinon, relancez ShadowMount+ ou la console.)
4. Ouvrez Régie5. Appuyez sur R1 jusqu'à l'engrenage (Réglages).
5. Choisissez « Depuis le téléphone ». Un QR code et un code à 6 chiffres
   s'affichent sur la télé.
6. Scannez le QR code avec votre téléphone (même réseau que la console), ou
   tapez dans son navigateur l'adresse affichée sur la télé.
7. Sur la page, remplissez chaque service : adresse (http:// ou https://, avec
   le port, par exemple http://192.168.1.10:8989) et clé d'API. Cochez
   « Certificat auto-signé » pour une adresse https:// au certificat auto-signé.
8. Touchez « Enregistrer sur la console ». Régie5 teste chaque service : chacun
   doit avoir une pastille verte dans Réglages.

Sans téléphone : copiez PPSA99520/config.example.json sous le nom config.json
dans le même dossier, remplissez-le sur votre ordinateur, copiez-le dans
/data/homebrew/PPSA99520/, puis choisissez « Tout tester » dans Réglages.

Où trouver les clés d'API
- Sonarr, Radarr : Settings > General > Security > API Key.
- Seerr : Settings > General > API Key.
- Jellyfin : Tableau de bord > Clés API > « + ».

Mise à jour
- Copiez le nouveau dossier PPSA99520 PAR-DESSUS l'ancien. Le zip ne contient
  jamais de config.json : le vôtre est conservé.
- Ne supprimez pas l'ancien dossier avant. Si cela arrive quand même, Régie5
  reprend la copie de config.json qu'il garde de son côté, et Réglages
  l'indique.

À savoir
- Régie5 ne parle qu'à vos serveurs, sur votre réseau local : rien ne part sur
  internet.
- config.json contient vos clés d'API en clair sur la console.
- Le Ménage (suppression de films et séries avec leurs fichiers) est désactivé
  par défaut ; il s'active dans Réglages, après un avertissement, et chaque
  suppression demande deux confirmations.
- « Ouvrir dans Jelly5 » n'est pas possible : la console ne laisse pas une app
  en lancer une autre. Options > « Chercher dans Jelly5 » indique le titre à y
  chercher.
- Désinstaller : supprimez /data/homebrew/PPSA99520.
