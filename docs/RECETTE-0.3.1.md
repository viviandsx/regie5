# Régie5 — Recette de la 0.3.1 sur PS5 (15 minutes)

Avant la publication : le zip de la release (`build/ps5/release-0.3.1/upload/PPSA99520.zip`),
installé par-dessus la 0.3.0, sur la console, avec la manette et un téléphone sur le même
réseau. Pas de journal dans une release : tout se juge à l'écran. Seule écriture : le
`config.json` de la console, réenregistré tel quel depuis la page du téléphone.

Une étape = une action. Après « → » : ce que tu dois voir. Si ce n'est pas ce que tu vois,
**ne publie rien** et note le numéro de l'étape.

## A. Installation

1. Ferme Régie5 sur la console.
2. Décompresse `PPSA99520.zip` sur le PC.
3. Copie le dossier `PPSA99520` par-dessus `/data/homebrew/PPSA99520/`.
4. Attends 30 secondes.
5. Regarde l'accueil → la tuile Régie5 est dans **Jeux** (plus dans Multimédia).
6. Lance Régie5 → l'Accueil s'affiche, avec tes données.

## B. Réglages

7. Appuie sur R1 jusqu'à l'engrenage → tous les services au vert.
8. Lis le bas de l'écran → « Version 0.3.1 », puis « Affichage : 3840 × 2160, 60 Hz ».
   Si ton réglage était resté sur 120 Hz : la même ligne, en jaune, avec « 120 Hz
   indisponible dans cette version ».
9. Va sur « Fréquence d'affichage : … » et appuie sur ✕ plusieurs fois → seulement
   « Auto (60 Hz) » et « 60 Hz », jamais « 120 Hz ». Laisse-le sur « Auto (60 Hz) ».

## C. Depuis le téléphone (le défaut de la 0.3.0)

10. Va sur « Depuis le téléphone », ✕ → un QR code et un code à 6 chiffres.
11. Scanne le QR code → la page s'ouvre sur le téléphone (pas « La page n'a pas pu être
    ouverte »).
12. Sans rien changer, appuie sur « Enregistrer sur la console » → la page dit
    « Enregistré. Régie5 teste les services : regardez la TV. » ; sur la télé, les
    services restent au vert.
13. ○ pour fermer la fenêtre.

## D. Fin

14. Ferme Régie5 → l'accueil de la PS5 est normal.
